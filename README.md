# La Renon Healthcare — Website Concept

An award-caliber, fully responsive concept redesign for **La Renon Healthcare Pvt. Ltd.**
Built as a self-contained static site — no build step required.

## Highlights
- Full-screen video hero with kinetic typography
- Full-screen navigation overlay
- 8 Divisions in a pinned horizontal-scroll gallery (native swipe on touch)
- Events & Participation tabbed panel, Latest News cards
- Animated counters, custom cursor, magnetic buttons, scroll-choreographed reveals
- Brand-red palette · Raleway + Inter · fully responsive (mobile / tablet / desktop)

## Run locally
```bash
python3 -m http.server 8842
# open http://localhost:8842
```
